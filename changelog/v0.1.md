# Changelog v0.1

**Дата:** 2026-06-04  
**Статус:** MVP — paper-торговля, один символ, Bybit market data

---

## Обзор

Первая рабочая версия **Shine Scalper**: backend на .NET 8, хранение в **SQLite**, стрим данных с Bybit, детектор уровней на 5m, сигналы пробоя, paper-исполнение сделок и React-дашборд с живым графиком.

---

## База данных

- **SQLite** — единственная БД в v0.1 (файл `shine-scalper.db` в каталоге Host при запуске)
- **EF Core 8** + `EnsureCreated` при старте приложения
- Таблицы: свечи, снимки уровней, сигналы, позиции, fills, equity snapshots, bot state, daily PnL

## Backend (.NET 8)

### Проекты solution

| Проект | Назначение |
|--------|------------|
| `ShineScalper.Core` | Доменные модели, enums, options, интерфейсы |
| `ShineScalper.Infrastructure` | SQLite, DbContext, репозитории |
| `ShineScalper.Bybit` | REST klines + public WebSocket |
| `ShineScalper.Engine` | Уровни, сигналы, risk, paper executor, orchestrator |
| `ShineScalper.Api` | REST API, DTO, SignalR hub |
| `ShineScalper.Host` | Точка входа, DI, `appsettings.json` |

### Bybit market data

- Bootstrap истории: **5m** и **1m** свечи (до 1000 баров) для **SOLUSDT** linear
- WebSocket: `kline.5`, `kline.1`, `tickers`
- Reconnect с exponential backoff
- Сохранение свечей в SQLite, публикация в SignalR

### Детектор уровней (5m / 48h)

- Swing high/low → кластеризация в **ценовые зоны**
- Подсчёт **касаний с отскоком** (support / resistance)
- Фильтры: `MinTouches`, `MaxLevelAgeHours`
- **Инвалидация:** support — `close < lower`; resistance — `close > upper`
- Пересчёт при закрытии 5m-свечи + при старте
- Снимки уровней в БД, кэш в памяти, push `levels` в UI

### Сигнальный движок (breakout)

- Подход к зоне за окно минут
- «В зоне» — по времени и числу тиков (ticker)
- Пробой: long через resistance, short через support (симметрично)
- Фильтры: max позиций, daily loss limit, позиция по символу
- Логирование принятых и отклонённых сигналов

### Risk + Paper trading

- Paper equity по умолчанию **10 000 USDT**
- Риск на сделку **2%**, плечо в конфиге **10x**, cap notional
- SL **за зоной** (BehindZone + buffer bps)
- Частичный TP **25%** на ближайших уровнях в сторону профита
- Комиссии и slippage в paper-модели
- Управление открытой позицией на каждом тике (SL / partial TP)

### Live trading

- **Не реализован** — `LiveOrderExecutor` выбрасывает `NotSupportedException`
- Режим `TradingMode: Live` в конфиге зарезервирован

## API и real-time

### REST (`http://localhost:5280`)

| Endpoint | Описание |
|----------|----------|
| `GET /api/health` | Статус, режим, WS, last price |
| `GET /api/candles` | Свечи (?interval, ?limit) |
| `GET /api/levels` | Активные уровни |
| `GET /api/positions` | Open + recent |
| `GET /api/trades` | История fills |
| `GET /api/config` | Публичные параметры торговли |
| `GET /api/equity` | Текущий equity + история |

### SignalR

- Hub: `/hubs/trading`
- События: `candle`, `levels`, `signal`, `position`, `trade`, `ticker`
