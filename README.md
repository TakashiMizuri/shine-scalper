# Shine Scalper

Бот для автоматизированной торговли на **Bybit** (USDT-M futures): пробои уровней, детекция уровней на **5m**, paper/live режимы, веб-дашборд с живым графиком.

## Документация

- **[Спецификация v0.1](docs/SPEC-v0.1.md)** — требования, стратегия, архитектура, план разработки.

## Статус

Проект в стадии **проектирования** (репозиторий инициализирован, код ещё не добавлен).

## Стек (план)

- **Backend:** C# / .NET 8, ASP.NET Core, SignalR, Bybit API V5  
- **Frontend:** React, TypeScript, Tailwind CSS, lightweight-charts  
- **MVP символ:** SOLUSDT
